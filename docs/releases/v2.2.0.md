# DLSS 5 Swapper v2.2.0 — Optional OptiScaler & Smarter Library

The biggest addition in **2.2.0** is **optional OptiScaler DLSS-NR integration**,
alongside new library tools, persistent History, improved recovery, and
38-language coverage for search, filters and installation warnings.

## ⭐ Headline: choose OptiScaler or ReShade per game

- Select **Rendering backend → OptiScaler DLSS-NR** in the game details,
  then **Apply backend change / Install** with the game closed.
- **ReShade remains the default.** OptiScaler is completely optional. Select
  ReShade and apply to return; each backend keeps separate settings.
- Downloads a pinned, SHA-256-verified
  [OptiScaler DLSS-NR v0.1.1.5](https://www.yx-sf.com/wiki/3057)
  from its author on first use (~130 MB); upstream batch scripts are not run.
- Requires **RTX 50 series**, **NVIDIA driver 616.56+**, and a **64-bit game
  with native DLSS enabled**. This is not a generic injector for non-DLSS
  games or emulators; use ReShade/Feeder for those.
- DX12 uses DLSS output by default. DX11/Vulkan uses the DX12 bridge with
  FSR output by default, while DLSS remains selected in the game's settings
  to provide inputs. Performance and image quality depend on the game.
- Vulkan backend changes require **Restore originals** first. Active global
  ReShade Vulkan installations must be restored before using OptiScaler;
  layers belonging to other games are not silently disabled.

## 🎮 Library and everyday usability

- **Real-time search** for games and emulators, combined with API, DLSS
  status/version, and add-on filters. Includes combined DX11/DX12 filtering.
- **Clickable counters** for DX12, DLSS presence and ready-to-install titles.
- **One unified library:** disable **Group games by store** in Settings to
  remove Steam/Epic/GOG sections. Your preference is saved.
- **Right-click menus** on Games and Recent Games: details, open folder,
  copy path, rescan one game, change cover, restore originals, and hide.
  Keyboard users can use Shift+F10 or the context-menu key.
- **History repaired:** successful installations, repeat installs, backend
  changes and restores remain recorded independently of the current backup.
- **Copy history and logs**, including the game installation log. Selectable
  diagnostic text also supports Ctrl+C. Review local paths before sharing.
- **38-language translations** for search, filters, related settings,
  compatibility warnings and native confirmation dialogs, with RTL support.

## 🔧 Installation, detection and recovery fixes

- **SWTOR / 64-bit DX9:** offers Feeder instead of an unusable native-only
  route, including cases with DLLs left by an earlier injection.
- **DX8 and DX9:** 32-bit DX8 and 32/64-bit DX9 route through the matching
  official **dgVoodoo2 2.87.4 → DX11 → Feeder** components. This avoids sending
  the Feeder effect to the legacy DX9 shader compiler.
- **Feeder 0.12.0:** matching shader, 32/64-bit clients and host from one
  verified release; correct ReShade architecture and pre-install Visual C++
  checks. Missing runtimes produce guidance before game files are changed.
- **Feeder configuration:** repairs motion-provider overrides, startup preset
  paths and effect ordering, enables the NR pass and removes the helper's
  accidental NR-toggle hotkey. Unrelated effects and tuning are preserved.
- **Small or nested executable detection:** removes the old size-only cutoff
  and recognises engine-module layouts used by Source/GoldSrc, Killing Floor,
  Far Cry 5 and Watch Dogs. Redistributables, mod tools and backups are not
  treated as game executables.
- **Cyberpunk 2077 / Phantom Liberty:** shared-install entries resolve to the
  base game with its artwork instead of showing only the DLC. Old scan/art
  cache results are refreshed.
- **Native DLSS installs:** preserve existing Streamline, frame-generation,
  ray-reconstruction and unrelated x86 files; avoid duplicate SR DLLs beside
  a game with a nested native runtime.
- **Safer backend switches:** keep original backups and a recovery journal;
  failed writes roll back to the prior file state. New backup sessions do not
  reuse stale originals after a game update.
- **Restore originals:** available even when the executable is missing or
  optional settings cannot be saved. Missing backup files are reported rather
  than silently deleting unknown files. Conflicting ENB/DXVK/loaders are not
  overwritten. MO2 Stock Game/Root Builder packs such as LoreRim must still
  be managed through their own modpack manager.

## 🕹️ Emulators and controlled scanning

Support continues for known emulator profiles including **DuckStation,
PCSX2, RPCS3, Dolphin, PPSSPP, Xenia and Cemu**, using ReShade/Feeder and their
supported renderer choices. Select the emulator folder and its active API.
Xenia receives conservative vector-validation and UI/masking settings, but
this remains an **experimental mitigation**, not a fix for every game's HUD.

**Full fixed-drive scanning stays OFF by default.** Folders/games you add are
still scanned normally, and Steam/Epic/GOG discovery remains available. Enable
the Settings toggle when you want drive-wide discovery; unwanted scan roots
can be removed. Search and filters do not start new drive scans.

## ⚠️ Anti-cheat and compatibility notes

Games with detected anti-cheat, including **ARC Raiders**, show a **red warning**
and an explicit choice for each install attempt. Installation is optional,
not globally blocked. It may still crash, prevent launch or cause an account
ban. Swapper never disables or bypasses anti-cheat. Restore does not require
accepting installation risks; other hardware and file-conflict checks remain.

- **Native DX10 is not supported by Feeder.** Choose the game's DX11 mode if available.
- **“No effects found” is not by itself an error on the native DLSS route.**
  Enable in-game DLSS and check ReShade's Add-ons tab. Feeder does require its effects.
- **Midnight Suns, RE5 and GTA IV crash reports are not declared universally
  fixed.** Please provide ReShade/Feeder and installation logs for diagnosis.
- Automated checks cover detection, all 38 feature locales, UI behaviour,
  and verified payload-copy/restore workflows in synthetic folders. They do
  not prove live-game, GPU or anti-cheat compatibility.
